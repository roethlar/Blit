## Verified sound (with the evidence that settled each)

- **The pruned set is complete before it ships.** `scan.finish().await`
  (`crates/blit-core/src/transfer_session/mod.rs:2067`) resolves before
  `scan.take_pruned()` (`:2109`). A scan error returns before any frame is
  sent, so the session faults rather than mirroring with a partial set.
- **The set survives decoration.** `DestSubtreeExcludedSource`
  (`transfer_session/local.rs:703`) and `ChecksummingSource`
  (`remote/transfer/source.rs:1077`) mutate the inner `SourceScan` through
  `replace_primary`, preserving `pruned`; `FilteredSource` overwrites
  `scan.pruned` only when it holds a recorder (`source.rs:977`). A decorator
  that built a fresh `SourceScan` would have silently dropped the set.
- **Source and destination cannot disagree on whether to send the frames.**
  Both ends test `mirrors_filtered_subset(&negotiated.open)`; only three
  production `SessionOpen` constructions exist
  (`remote/transfer/session_client.rs:156,443`, `transfer_session/local.rs:777`)
  and the responder sees the initiator's own message. So the violation branch
  at `mod.rs:4601-4606` cannot fire on a well-formed session.
- **Deletion cannot go recursive.** `DirectoryMode::EmptyOnly { tolerate_nonempty }`
  (`mod.rs:4130`), with `tolerate_nonempty` true on every `FilteredSubset`
  mirror — the only mode in which pruned paths exist. A directory holding a
  protected child fails its `rmdir` and is tolerated. This is what makes the
  mechanism safe even where `keep_dirs_holding_left_out_entries`
  (`mirror_planner.rs:333`, gated on `!filter.is_empty()`, which does not
  count the `destination` field) does not run.
- **`push_state`'s min-start merge is sound.** `**/` absorbs any prefix, so
  the earliest start of a combined `**/glob` subsumes every later one
  (`transfers/filter.rs:1396-1420`).
- **The glob reading fails closed.** Any component globset refuses makes
  `path_steps` return `None`, leaving the whole rule to the as-written filter
  (`filter.rs:1356-1378`). `path_components` likewise returns `None` for an
  escaped or class-internal `/`.
- **Contract 8 is coherent.** Strict refusal on mismatch at `mod.rs:963`;
  proto field 23 collides with nothing; `CHANGELOG.md` (19, 113),
  `docs/RELEASE_NOTES_1_0.md:140`, `README.md` and
  `docs/TRANSFER_SESSION.md` (43, frame table, the new v8 paragraph) all
  say 8.

## Observations (not admitted findings)

### O1 — MEDIUM (FAST): the destination's pruned set is unbounded in memory and in lstats

`transfer_session/mod.rs:4608` does `pruned_paths.extend(pruned.paths)` with no
cap, and `transfers::filter::resolve_pruned_on_disk` (`filter.rs:899-912`)
lstats every path before the deletion walk. `MAX_PRUNED_FRAME_BYTES` bounds a
*frame*, not the set. Every other wire path list in this codebase is truncated
by the **sender** against a total budget
(`MAX_WIRE_FAILED_PATHS_ENCODED_BYTES`, `remote/transfer/sink.rs:74,541`); the
pruned sender has no equivalent.

Scenario: `blit mirror --exclude '*.o'` over a tree with ~5M object files sends
~5M paths; the destination holds them all as `String`s (order 300 MB) and
performs ~5M extra `lstat`s before deleting anything. The deletion pass's cost
therefore scales with what the source **excluded**, a quantity unrelated to the
destination tree's size.

Mitigating: cr-g3fix6-2 admits the scaling by analogy to the manifest, and
`source_files: HashSet<String>` already has the same shape, so this is
consistent with the existing architecture rather than new in kind.
**Assumption, not measured:** the byte and lstat figures are reasoned from the
code, not benchmarked.

### O2 — LOW/MEDIUM (FAST): the cr-g3fix6-3 bound covers one glob layout only

`push_state` merges states solely for `Step::AnyDepth { crossing: Some(_) }`
(`filter.rs:1397-1400`). A `Step::Glob { crosses: true }` that *follows* a
combined `**/glob` still retains one state per distinct start, so a rule shaped
like `--exclude '**/*x/*y/missing'` reproduces the depth-quadratic growth the
reviewer measured for `**/*/missing`. Merging is genuinely unsound there — for
a bare crossing glob an earlier start is not more permissive — so this is a
real residual rather than an oversight, and cr-g3fix6-3's Known gaps already
says "Other glob layouts were not benchmarked".
**Assumption, not measured:** reasoned from the merge condition, not timed.

### O3 — coverage: the end-to-end deletion guards execute on macOS only

`mirror_delete_pass_keeps_the_destinations_entry_for_a_pruned_path`
(`transfer_session/mod.rs`, the cr-g3fix6-2 guard) and the `GLOB_PAIRED`
guards in `crates/blit-cli/tests/exclude_contract.rs` run each case only where
the filesystem pairs the two spellings. Run on this Windows/NTFS host
2026-10-19, **all three cases skipped** — sharp-s, long-s and NFD alike — and
the test passed vacuously:

```
skipping sharp s: the filesystem does not pair "aß" with "aSS"
skipping long s: the filesystem does not pair "ſ" with "s"
skipping nfd: the filesystem does not pair "e\u{301}" with "É"
skipping: no case pairs on this filesystem
```

cr-g3fix6-2's guard proof records the same for ext4. So the headline
data-loss protection is proven end-to-end **only on APFS**; the Windows and
Linux CI legs exercise the component pieces alone. Those pieces are real
coverage — `the_pruned_paths_resolve_as_stored_name_pairs_each_component` does
exercise case pairing on NTFS, and the recording, framing and protocol-violation
guards are platform-independent — but a Windows-specific regression in the
pairing path would not be caught. Known, not hidden; recorded here because
`.agents/repo-guidance.md` holds that a guard which cannot go red where you
are is not evidence.

### O4 — nit: a duplicated predicate that could decouple

`transfer_session/local.rs:827` gates recording on
`mirror_kind == MirrorMode::FilteredSubset`, while every other site uses
`mirrors_filtered_subset(&open)`, which also requires `mirror_enabled`. They
agree today only because `local.rs:769-776` sets `FilteredSubset` exclusively
when `options.mirror` is true. Should that ever decouple, the local carrier's
source would emit `ManifestPruned` into a destination that rejects it as a
protocol violation (`mod.rs:4601-4606`), faulting the transfer. One line, no
behaviour change: call `mirrors_filtered_subset(&open)` there too.
